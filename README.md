
# Portfolio1

This is an early-stage personal portfolio website built as a learning project at the beginning of my web development journey. The goal of this project was to experiment with layout design, animations, responsiveness, and visual presentation using core front-end technologies without any backend.

---

## About the Project

Portfolio1 is a multi-section static website that presents personal information, skills, projects, and contact links in a visually rich format. The site focuses heavily on styling, transitions, and section-based storytelling rather than application logic.

It is structured as a single-page scrolling experience with clearly separated sections.

---

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts
- Static image assets

## Sections Overview

### Home
- Full-screen hero section
- Background image-based layout
- Intro text and navigation
- Responsive dropdown navigation for smaller screens

### About
- Profile image with hover effects
- Introductory text overlay
- Animated reveal on hover
- Split layout using flexbox

### Projects
- Carousel-based project showcase
- Image-heavy project cards
- Hover scaling and transitions
- Built using Bootstrap carousel with custom styling

### Skills
- Categorized skill lists
- Main skills and soft skills
- Animated hover effects
- Background video/gif section

### Contact
- Social media and professional links
- Icon-based link buttons
- Emphasis on call-to-action
- Visual glow effects for emphasis

### Footer
- Navigation shortcuts
- Copyright information

## How to Run

This is a static frontend project.

Option 1  
Open `index.html` directly in a browser.

Option 2 (recommended)  
Use a local development server such as VS Code Live Server for proper asset loading.

---

## Design Focus

- Heavy use of background images
- CSS hover-based animations
- Responsive layouts using Flexbox and Bootstrap
- Visual experimentation over code optimization
- Manual styling without preprocessors

---

## Limitations

- No backend or dynamic data
- No form submission handling
- Images are not optimized for production
- Some animations are hover-dependent
- Not accessibility-optimized

---

## Learning Outcomes

- Structuring multi-section layouts
- Managing large asset folders
- Using Bootstrap alongside custom CSS
- Applying transitions and hover effects
- Responsive design basics

## Notes

This project represents an early learning phase and prioritizes experimentation and creativity over best practices or performance optimization.
